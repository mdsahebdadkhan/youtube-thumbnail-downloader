How it works

  1. Copy the link to any public YouTube video, Short, or live stream.
  2. Paste it above and tap Get thumbnails.
  3. Pick a size and download — the largest is usually 1280 × 720. If a video has no HD thumbnail, that card will be marked unavailable and the next size is your best option.

Which size should I use?

Maxres (1280×720) — blog headers, presentations, and re-uploads where quality matters.

HQ (480×360) — always available, even on older videos. Good for embeds and docs.

MQ (320×180) — small previews and lists where file size matters more than detail.

Direct video downloads

Paste a link that points straight to a video file — it should end in .mp4, .webm, .mov or .m4v. The player previews it, then Download saves that exact file.

A YouTube watch / Shorts page link isn’t a direct file, so it won’t work in the video tool — use it in the thumbnail tool above, or open it on YouTube for offline saving where YouTube offers it.

If a server blocks in-page downloading, the tool opens the file so you can save it from there.
